# 二、相关命令
## 1.查询APN配置
```
PORT="/dev/ttyUSB2"

echo -e -n "AT+CGDCONT?\r\n" > $PORT

或
	echo -e -n "AT+CGDCONT?\r\n" > /dev/ttyUSB2 && cat dev/ttyUSB2
```
## 2.查询信号强度

```
echo -e -n "AT+CSQ\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 3.查询网络注册状态
```
echo -e -n "AT+CGREG\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```

## 4.判断是否注上4G网络

```
echo -e -n "AT+CEREG?\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 5.判断是否识别到卡
```
echo -e -n "AT+CPIN?\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 6.查询设置功能模式
```
echo -e -n "AT+CFUN?\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 7.查询是否是自动搜网
```
echo -e -n "AT+COPS?\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```

## 8.检查模块的 BAND 配置是否被修改
```
echo -e -n "AT+QCFG=\"band\"\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```

## 9.锁定频段
```
echo -e -n "at+qcfg=\"band\",bff,1C000000000\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 10.检查模块是否锁网络制式
```
echo -e -n "AT+QCFG=\"nwscanmode\"\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 11.检查信号质量
```
echo -e -n "AT+QENG=\"servingcell\"\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 12.频点锁定
```
echo -e -n "at+qnwlock="common/lte",1,40936,334\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 13.锁定4G（移远立即生效）
```
echo -e -n "AT+QCFG=\"nwscanmode\",3,1\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```
## 14.Pin码解锁
```
echo -e -n "AT+CPIN=\"密码\"\r\n" > dev/ttyUSB2 && cat dev/ttyUSB2
```

## 2.初步分析

### （1）调试命令

1.1 抓取完整的打印：logcat -b radio -v time
1.2 查看so文件及相关配置：getprop | grep ril
1.3 查看 SIM 卡 是否 ready，运营商等等：getprop | grep gsm
1.4 查看设备节点：ls /dev/ttyUSB*
1.5 查看网络相关设备：busybox ifconfig -a
1.6 查看网络接口的详细配置信息：netcfg


3.1 抓取连网过程中pppd或者dhcpcd程序的日志
adb logcat -s pppd
adb logcat -s dhcpcd
这个是分析连网问题时使用的，如果使用的是ECM拨号，则抓取dhcpcd日志，如果使用的是PPP拨号，则抓取pppd日志，系统默认使用ECM拨号，可以通过系统属性ril.dial.mode修改

3.2 通过AT指令直接查询模块内部的运行状态
指令执行过程如下：
adb shell          //进入Linux 环境
stop ril-daemon    //停止RIL
./AT              //运行发送AT指令的工具，该工具由模组商提供

为什么要先停止RIL再使用AT命令？
因为RIL服务自身会不停地给模块发送AT命令，如果你没stop ril-daemon再去手动发送AT命令的话就会有阻塞，导致你发送的AT命令后返回的结果会很慢或者没有返回。

4.1 判断RIL库是否已经加载并运行
******** Enter RIL_Init() ********
RIL库开始运行时会打印上述日志，从Android系统开机起抓取radio log，如果不存在上述字样，则说明RIL库没有正确加载。需要检查ril-daemon服务是否添加并正确运行。

4.3 判断模块是否已经注册到运营商的网络
在radio log中搜索如下几个AT指令的返回结果：
AT+CPIN?    //SIM卡状态
AT+CSQ      //信号强度
AT+ZPAS?    //注册状态


AT+CSQ
+CSQ: 31,0
OK
* 如果指令的返回结果中有ERROR字样，说明模块状态有问题
* 如果第一个数字为个位数或者为99，则说明信号非常差

(1)radio log中搜索“SETUP_DATA_CALL ********”字样，这里会启动连接网络的流程，可以看到后续流程中出现了何种错误



## 3.APN

**APN（Access Point Name，接入点名称）** 是移动网络（如 4G/5G）中用于标识设备如何接入互联网的关键配置。它相当于一个“网关”，告诉运营商的网络：

- **你的设备应该连接哪个网络**（如互联网、企业内网）。
- **使用哪种认证方式和 IP 分配策略**。

## 4.PPP和QMI拨号方式

### PPP拨号

PPP(Point-to-Point Protocol)是一种传统的拨号协议，通过**串行链路**建立网络连接。

```
# 典型PPP拨号命令
pppd /dev/ttyUSB3 115200 nocrtscts \
connect 'chat -v "" "AT+CGDCONT=1,\"IP\",\"cmnet\"" "ATDT*99#" CONNECT' \
noipdefault defaultroute usepeerdns 0.0.0.0:0.0.0.0
```

日志分析：
```
tail -f /var/log/messages | grep pppd
# 典型日志：
# pppd[1234]: local IP address 10.10.10.10
# pppd[1234]: remote IP address 10.64.64.64
```


### QMI拨号

QMI(Qualcomm MSM Interface)是高通开发的专有协议,通过USB CDC驱动直接控制模块。

```
# 使用libqmi工具
qmi-network /dev/cdc-wdm0 start
qmi-network /dev/cdc-wdm0 status
```

日志分析：
```
journalctl -u ModemManager -f
# 典型日志：
# qmi_wwan 1-1.4:1.4 wwan0: QMI msg tx'd
# qmi_wwan 1-1.4:1.4 wwan0: QMI msg rx'd
```


### 对比

| 特性   | PPP           | QMI                |
| ---- | ------------- | ------------------ |
| 协议效率 | 较低（有额外开销）     | 高（直接内核通信）          |
| 兼容性  | 几乎所有模块        | 仅高通方案模块            |
| 多路复用 | 不支持           | 支持                 |
| IP分配 | 手动处理          | 自动管理               |
| 延迟   | 较高            | 较低                 |
| 调试难度 | 容易（AT可见）      | 困难（需专用工具）          |
| 典型模块 | 华为ME909s，EC20 | Quectel EG系列，RM500 |
