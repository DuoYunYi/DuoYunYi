
# 一、信号格数跳变问题

信号格数接口：
![[img_v3_02n6_1ae146ac-be74-49d4-94f2-b076698f542g.jpg]]

aml_sdk/frameworks/base/telephony/java/android/telephony/CarrierConfigManager.java
```
sDefaults.putBoolean(KEY_USE_ONLY_RSRP_FOR_LTE_SIGNAL_BAR_BOOL, true);
```

- **`true`**：仅使用 **RSRP（Reference Signal Received Power）** 计算 LTE 信号格（忽略 RSRQ/SINR）。
- **`false`**（默认）：综合 **RSRP + RSRQ + SINR** 计算信号格（更准确但可能更复杂）。

# 二、比利时驻网问题
## 1.设置4G only
aml_sdk/device/amlogic/common/products/libquectel-ril/libquectel-ril.mk

```
PRODUCT_PROPERTY_OVERRIDES += \

ro.telephony.default_network=11 \
```

getprop | grep -i ro.tele

## 2.禁止ims

AT+QCFG="nwscanmode",3,1设置为lte only 方案 ，直接配置安卓代码  ro.telephony.default_network的值改11即可

aml_sdk/device/amlogic/common/products/libquectel-ril/ql-ril.conf

```
disable_ims=1
```

验证：
```
stop ril-daemon 

echo -e "AT+QCFG=\"ims\" \r\n" > /dev/ttyUSB2 

cat /dev/ttyUSB2
```
