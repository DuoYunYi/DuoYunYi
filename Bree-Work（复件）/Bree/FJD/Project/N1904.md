## 2.卸载apk

```
adb root 
adb remount 
adb shell rm -rf /system/priv-app/FjSmartkit 
adb shell rm -rf /data/data/com.fj.smartkit 
adb shell rm -rf /mnt/sdcard/smartCache 
adb reboot
```
